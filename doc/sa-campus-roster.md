# 四季藝術 · 校區人員名冊（paperwork）

用途：**單一資料來源**，同時服務兩件事——
1. **既有 agent 的 team 重新標記**（比對姓名 → `[校區, 組]`）。
2. **未來建立 agent 時的輸入**：連同 `skills/sa-agent-onboarding/SKILL.md`（代理人建置技能）與
   `doc/sa-org-chart.md`（組織圖／回報線）一起使用，操作者只需補上 **Email**。

> ⚠️ **不自動建立 agent**。名冊中尚未有對應 agent 的人 → 保留為資料，等實際要建時再依技能建置。
> Email 欄目前多為 TBD，建 agent 時補上（`adapterConfig.assignedUserEmail`）。

## 團隊標記格式
`metadata.teams = [校區, 組]`。校區：仁美/市政/西屯/黎明/北屯/總管理處。
校區首長（總園長/園長/副園長）→ 組＝「園務」；跨校總園長 → `["領導團隊"]`；總管理處處長 → `[總管理處,處長室]`。
校護不再是 team → 併入該校「總務管理組」。跨校巡輔僅仁美。
