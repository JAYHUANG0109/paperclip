# 四季｜職務別 Agent 執掌目錄（Role → Responsibilities Catalog）

> **用途**：從此以後，agent 以「職務／職級」為單位建立——**同一職務、同一職級的人（使用者／agent）共用相同的 scope 與 instructions**。本檔是建立 agent 時可查詢的權威來源，讓日後建立 agent 更省力、更一致。
>
> **每個職務一段 `yaml` 區塊**（機器可解析，欄位與 `packages/teams-catalog` 的 agent frontmatter 對齊：`role` / `title` / `reportsTo` / `skills`），下方接責任清單。要把某職務落地成 agent 模板時，可直接把 `responsibilities` 抄進該職務 `AGENTS.md` 的 `## 執掌` 段。
>
> **報告關係（reportsTo）**：一般以「**直接主管**」為準——即**週誌主簽者**。本檔給的是校端的預設樣式；**總部**部分依「跨校分工資料」而定（該資料小智已同步到週誌模組資料庫，非本檔範圍）。
>
> **資料來源**：週誌模板職務提醒清單（Google Sheet）＋ 114-1 新人師訓簡報
> **最後更新**：115.06.25（民國）
> **範圍**：校端（campus-side）職務執掌

## 總部（跨校）

總部職務不在本校端清單內，依「**跨校分工資料**」建立與指派——該資料小智已同步到**週誌模組資料庫**。建立總部 agent 時，以週誌模組的跨校分工＋直接主管（週誌主簽者）為準。

---

## 建立 agent 時怎麼用本目錄

1. 依人員的**職務**在本檔找到對應區塊。
2. 用該區塊的 `role` / `title` / `level` 設定 agent 身分；**同 `role`（或同 `level`）的人共用同一份 scope 與 instructions**。
3. 把 `responsibilities` 作為該 agent `AGENTS.md` 的執掌骨幹（可再依創辦人／園長的客製化問卷補上口吻與規則）。
4. `reportsTo` 以**直接主管（週誌主簽者）**落地；總部以跨校分工資料為準。
5. 要正式模板化，可把每個職務落成 `packages/teams-catalog` 的一個 agent 原型（frontmatter 欄位已對齊）。
