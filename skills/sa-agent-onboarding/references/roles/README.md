# 職務登錄（每個職位一個檔）

用途：建立代理人時，**職掌 / 🔴最高原則 / 界線紅線 / 決策權限三層** 的唯一出處。
`skills/sa-agent-onboarding/SKILL.md` 的「四、指令組裝」把這四段填進指令樣板；
操作者只替換個人層級變數（姓名、校區、直接主管姓名），**不得自由發揮**。

## 命名規則

`doc/roles/<職位>.md`，檔名＝ `POSITIONS`（`ui/src/lib/org-chart-options.ts`）裡的職位字串。
例：`人發主任.md`、`行銷組長.md`。職位不在 `POSITIONS` → 先加進去再建檔。

## 檔案格式（每個檔都長這樣）

```markdown
# <職位>

- **層級**：L2 / L4 / L5
- **單位**：總管理處／<部門>　或　校區／<組>
- **直接主管**：<職位>（實例化時換成人名）
- **現職**：<姓名>（可空）

## 職掌
①… ②… ③…

## 🔴 最高原則
…

## 界線 — 絕對不能（紅線）
…
（並套用 SKILL.md「三、全體共通底線」全部條款）

## 決策權限（三層）
- **可自己做**：…
- **先知會協調（→ …）**：…
- **上呈核准（→ …）**：…
```

## 回報線

一律查 `doc/sa-org-chart.md`。總部線：組員 → 組長 → 主任 → 部門主管/副理 → 處長 → 創辦人。
校區線：組員 → 組長 → 主任 → 副園長 → 園長 → 總園長 → 創辦人。
